Detailed Description

Breakout demo implemented using the Bagel ECS engine.

The game is built from ECS entities composed of small components such as Transform, Drawable, Collider, Intent, and tag components. Systems process entities by their component masks and communicate through components.

Box2D is used for movement simulation and collision detection.

\doxysubsection{Detailed Description}
\doxylink{class_game_1_1_breakout}{Breakout} demo implemented using the Bagel ECS engine. 

\doxylink{class_game_1_1_breakout}{Breakout} owns the SDL window, renderer, spritesheet texture, and Box2D world. It creates the ECS entities that make up the game level and runs the frame loop that updates input, physics, collision handling, and rendering.

All game logic lives in small, independent systems that iterate over entities by component mask, following the same pattern as the lecturer\textquotesingle{}s Pong implementation. No entity is searched by identity; every system operates on whichever entities match its mask.

Box2D sensors are used for brick hits and the death zone below the paddle. Direct contact data is used for paddle deflection.

\begin{DoxyInvariant}{Invariant}
\doxylink{class_game_1_1_breakout_a5b0ccaef73debc0bb9ee5ffab402858a}{valid()} is true only after SDL resources, the spritesheet texture, and the Box2D world were created successfully. 

Each entity with \doxylink{struct_game_1_1_collider}{Collider} is expected to also have \doxylink{struct_game_1_1_transform}{Transform} so Box2D positions can be synchronised into ECS state. 

Each rendered entity is expected to have both \doxylink{struct_game_1_1_transform}{Transform} and \doxylink{struct_game_1_1_drawable}{Drawable} components. 
\end{DoxyInvariant}
